## A. Найденные проблемы (аудит 2026-11-07)

Состояние на момент аудита: `tsc` — без ошибок, `lint` — 1 предупреждение, `npm test` — **2 из 10 тестов падают**.

### Ошибки (баги)
- [ ] **A1. Сломан парсинг токена** в `src/mocks/handlers/employees.ts` и `shifts.ts`:
      `authHeader.replace('******', '')` вместо `'Bearer mock-jwt-'` → автор действия неизвестен:
      менеджер получает уведомления о своих же действиях, отправитель всегда «Staff Manager».
      Вынести `getUserIdFromAuthHeader` в общий модуль `src/mocks/handlers/utils.ts`.
- [ ] **A2. Сдвиг дат на один день** — `toDateString()` в `src/utils/dateUtils.ts` использует `toISOString()` (UTC).
      В Чехии (UTC+1/+2) локальная полночь превращается в предыдущий день → график смен, «сегодня»,
      запрос `weekStart` смещены. Нужно форматировать по локальной дате.
- [ ] **A3. Смена без времени показывается как ночная (N)**: в `ShiftsPage` `Number('') = 0 < 6`.
      Нужно поле `type: 'DAY' | 'NIGHT'` у смены (см. спецификацию) и выбор D/N сохранять в смену.
- [ ] **A4. Клик по пустой ячейке ставит D/N в localStorage даже если модалку отменили** — остаётся «фантомная» смена.
- [ ] **A5. `formatTime('')`** на Dashboard выдаёт `12:undefined AM` для смен без времени.
- [ ] **A6. Коллизия ID в моках**: `nextId` сбрасывается на 100 при перезагрузке, а уведомления/объявления
      восстанавливаются из localStorage → повторяющиеся `id` (`not-101`…).
- [ ] **A7. Сотрудники и смены в моках не сохраняются** при перезагрузке, а уведомления о них — сохраняются (рассинхрон).
- [ ] **A8. 2 падающих интеграционных теста** (`src/features/app.integration.test.tsx`: notifications clear all, unread counter).
- [ ] **A9. Пересечение смен не учитывает ночь через полночь** (`hasTimeOverlap` сравнивает строки).
- [ ] **A10. Lint warning** `react-hooks/incompatible-library` в `ShiftsPage` (`watch`) — заменить на `useWatch`.
