### Ошибки (баги)
- [x] **A1. Сломан парсинг токена** в `src/mocks/handlers/employees.ts` и `shifts.ts`:
      `authHeader.replace('******', '')` вместо `'Bearer mock-jwt-'` → автор действия неизвестен:
      менеджер получает уведомления о своих же действиях, отправитель всегда «Staff Manager».
      Вынести `getUserIdFromAuthHeader` в общий модуль `src/mocks/handlers/utils.ts`.
- [x] **A2. Сдвиг дат на один день** — `toDateString()` в `src/utils/dateUtils.ts` использует `toISOString()` (UTC).
      В Чехии (UTC+1/+2) локальная полночь превращается в предыдущий день → график смен, «сегодня»,
      запрос `weekStart` смещены. Нужно форматировать по локальной дате.
- [x] **A3. Тип D/N смены без времени** хранится в `Shift.type`; время начала и конца можно не задавать.
- [x] **A4. Фантомные D/N при отмене** устранены: тип сохраняется после успешной записи смены, H/S/× — через API отсутствий.
- [x] **A5. `formatTime('')`** на Dashboard выдаёт `12:undefined AM` для смен без времени.
- [x] **A6. Коллизия ID в моках**: `nextId` сбрасывается на 100 при перезагрузке, а уведомления/объявления
      восстанавливаются из localStorage → повторяющиеся `id` (`not-101`…).
- [x] **A7. Сотрудники и смены в моках не сохраняются** при перезагрузке, а уведомления о них — сохраняются (рассинхрон).
- [x] **A8. 2 падающих интеграционных теста** (`src/features/app.integration.test.tsx`: notifications clear all, unread counter).
- [x] **A9. Пересечение смен не учитывает ночь через полночь** (`hasTimeOverlap` сравнивает строки).
- [x] **A10. Lint warning** `watch` заменён на `useWatch`.

- [x] **A11. `FormField` не связывал `<label>` с полем** (доступность, тесты по label) — исправлено через `useId`.
